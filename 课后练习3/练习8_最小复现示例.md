# 练习8：创建最小可复现示例

## 选定的 Bug
`sdt-greet --name " "` 输出 `Hello, !` 而不是报错退出（第10题遇到的bug）

## 原始完整代码
```python
import argparse

def main():
    p = argparse.ArgumentParser()
    p.add_argument("--name", required=True)
    a = p.parse_args()
    print(f"Hello, {a.name}!")

if __name__ == "__main__":
    main()

## 剥离无关内容后（最小复现示例）
import argparse

p = argparse.ArgumentParser()
p.add_argument("--name", required=True)
a = p.parse_args()
print(f"Hello, {a.name}!")
